# jaimemartinezd.github.io

Web personal de Jaime Martínez Domínguez, Data Engineer.

- `index.html`: toda la web (HTML + CSS + JS, sin frameworks).
- `og-image.png`: imagen de vista previa al compartir el enlace (1200×630).
- `cv/`: CV en español e inglés (PDF).
- `fonts/`: tipografía Inter alojada aquí (licencia OFL en `fonts/OFL.txt`).

## Editar

- **Textos:** objeto `I18N` al final de `index.html` (claves `es` y `en`).
- **Foto:** instrucciones en el CSS de `.avatar`.
- **Tecnologías "aprendiendo":** quita la clase `chip--learning` cuando las domines.
- **Nuevo proyecto:** copia un `<article class="project">` dentro de `.projects` y añade sus textos a `I18N`.
